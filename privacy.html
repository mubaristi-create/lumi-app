Lumi məxfilik siyasəti

Yenilənmə tarixi: 12 noyabr 2026

Bu səhifə Lumi tətbiqində və onun web versiyasında məlumatların istifadəsini izah edir. Tətbiqin operatoru Lumi Studio-dur. Məxfilik və hesabla bağlı müraciət: mubaristi@gmail.com.

Hesab və profil

Qeydiyyat və giriş üçün e-poçt ünvanı, hesab identifikatoru və autentifikasiya məlumatları Supabase Auth vasitəsilə işlənir. Google ilə giriş seçildikdə Google hesabının əsas profil və e-poçt məlumatları autentifikasiya üçün istifadə olunur. Lumi Gmail məktublarınıza və Google Drive fayllarınıza giriş istəmir. Seçdiyiniz istifadəçi adı, avatar və təqdim etdiyiniz digər profil məlumatları profil funksiyalarında istifadə edilir.

Oyunlar, xallar və liderlər

Oyun nəticələri, mərhələ irəliləyişi, mükafat qəbzləri və balans əməliyyatları oyunu davam etdirmək, düzgün xal hesablamaq və təkrar mükafatlandırmanın qarşısını almaq üçün saxlanılır. Liderlik bölməsində istifadəçi adı, avatar, nişan və yarış xalı görünə bilər; tətbiqdə mövcud görünmə ayarı bu bölməyə təsir edir.

Cihazda saxlanılan məlumatlar

Avtomatik giriş üçün sessiya tokenləri cihazda saxlanılır; şifrə açıq formada saxlanılmır. Android-də sessiya Android Keystore ilə şifrələnir, uyğun web brauzerdə WebCrypto və IndexedDB istifadə olunur. Səs ayarları, lokal oyun gedişi və son təsdiqlənmiş profil məlumatlarının keş nüsxəsi də cihazda saxlanıla bilər. Hesabdan çıxış sessiyanın yerli nüsxəsini təmizləyir. İnternetin müvəqqəti kəsilməsi özü hesabdan çıxış yaratmır.

Reklamlar

Android versiyası Google AdMob və istifadəçi razılığı üçün Google UMP kitabxanalarından istifadə edir. Reklam xidmətləri cihaz və tətbiq məlumatlarını, reklam identifikatorlarını, IP ünvanını, diaqnostika və reklam qarşılıqlı əlaqə məlumatlarını öz siyasətlərinə uyğun emal edə bilər. Razılıq tələb edilən bölgələrdə reklam sorğuları razılıq mexanizminə uyğun göndərilir. Mövcud olduqda reklam məxfilik seçimləri tətbiq ayarlarından açılır. Mükafatlı reklam könüllüdür; bonus üçün Google tərəfindən imzalanmış qəbz, texniki istifadəçi identifikatoru və birdəfəlik sorğu identifikatoru serverdə yoxlanılır. Test paketləri Google test reklamlarından istifadə edir.

Əlavə məlumat: Google məxfilik siyasəti, Google reklam texnologiyaları, Supabase məxfilik siyasəti.

Təhlükəsizlik və xidmət təminatçıları

Supabase hesab, verilənlər bazası və server funksiyalarını təmin edir. Web versiyasının yayımlanmasında GitHub Pages istifadə olunur. Bu xidmətlər texniki sorğu və təhlükəsizlik məlumatlarını öz qaydalarına uyğun emal edə bilər. Balans mükafatları serverdə yoxlanılır; sessiya tokenləri və şifrələr reklam diaqnostikasına yazılmır.

Telefon bildirişləri · Push notifications

İcazə verdikdə Android telefon bildirişləri Google Firebase Cloud Messaging vasitəsilə göndərilir. Cihazın bildiriş tokeni, təsadüfi quraşdırma identifikatoru, hesab identifikatoru və bildiriş seçimləri Supabase-də saxlanılır; mesajın çatdırılması üçün token və bildiriş mətni Google-a ötürülür. Saatlıq xatırlatma, gündəlik bonus və sıralama bildirişlərini ayarlardan söndürə bilərsiniz. Eyni bildiriş hesabınızın bildiriş bölməsində saxlanılır. Hesab silindikdə ona bağlı cihaz qeydləri də silinir.

With permission, Android notifications are delivered using Google Firebase Cloud Messaging. Supabase stores the device notification token, random installation identifier, account identifier and notification preferences. Google receives the device token and notification content to deliver the message. Hourly reminders, daily bonus and ranking alerts can be disabled in notification settings. The same message remains in your in-app inbox. Device records linked to an account are removed when that account is deleted.

Saxlama və müraciətlər

Hesab və oyun məlumatları xidmətin işləməsi, hesabın qorunması və mükafat əməliyyatlarının yoxlanması üçün istifadə olunur. Hesab məlumatlarını düzəltmək, onlara çıxış və ya hesabın silinməsini istəmək üçün yuxarıdakı əlaqə ünvanına müraciət edin. Müraciətin hesab sahibindən gəldiyini yoxlamaq lazım ola bilər. Tətbiqi cihazdan silmək serverdəki hesabı avtomatik silmir.

Uşaqlar və dəyişikliklər

Yaşı müəyyən edilməyən istifadəçilər üçün hazırkı Android reklam konfiqurasiyası konservativ uşaq/yaş məhdudiyyətləri və G məzmun reytinqi tətbiq edir. Valideyn və ya qəyyum uşağın hesab məlumatları ilə bağlı əlaqə ünvanına müraciət edə bilər. Məlumat emalı dəyişdikdə bu səhifə və yenilənmə tarixi dəyişdiriləcək.
